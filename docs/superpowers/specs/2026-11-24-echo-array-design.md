# 回声阵 v1.0 设计规格（归档）

> 日期：2026-11-24　状态：v1 单机人机版
> 详细需求见 [../../需求文档.md](../../需求文档.md)，架构见 [../../技术方案.md](../../技术方案.md)。

## 范围

- 2–4 人；v1 真人 1 名 + AI 补足。
- 54 张牌（52 花色 + 小王 + 大王）；12 张入阵（3×4），每人 4 张手牌。
- 回合行动：翻牌配对 / 普通替换干扰（限 3 次/人/局，设置 1–5）/ 小王窥视 / 大王强换。
- 结束：阵空且抽牌堆耗尽；收集张数最多胜，同点按配对对数破平。

## 技术基线

- core 纯 JS 状态机（`src/core`），composable 封装 Vue 视图与 AI 调度（`src/composables`）。
- 测试：Vitest node 环境，种子 RNG 可复现；43 个用例。
- 预留端口 3006；v1 无服务端，二期补 WebSocket 房间。

## 关键决策

- 干扰是有代价的稀缺资源：普通替换计次数，王牌行动不计次但全局各一张。
- AI 难度由记忆准确率 / 召回准确率 / 干扰频率参数控制，不以压缩思考时间为主要手段。
- 视图脱敏：他人手牌与 AI 记忆不下发；背面牌不携带牌面数据。
